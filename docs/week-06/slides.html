AI applications in 3D Modelling

Understanding how AI learns, represents, and generates 3D content.

Why 3D?

3D data underpins AR/VR, robotics, simulation, games, architecture, and design.

AI enables automatic creation and understanding of 3D structures from limited data.

What is 3D Representation?

3D data describes geometry (shape) and appearance (texture/materials).

There are multiple ways to represent 3D — each with trade-offs in accuracy and efficiency.

Main Types of 3D Representations

  • Point Clouds: sets of (x, y, z) points
  • Meshes: vertices + edges + faces
  • Voxels: 3D pixels in a grid
  • Implicit Fields: continuous functions (e.g., NeRF, SDF)

Point Clouds

Simple and flexible: just coordinates and sometimes color.

- Used by LiDAR sensors and 3D scanners.

- Challenge: irregular structure — needs specialized neural networks (PointNet, PointNet++).

Meshes

Most common in graphics: connected vertices forming triangles.

- Efficient and easy to render, but difficult for neural networks to learn directly.

Voxels

3D equivalent of 2D pixels — uniform cubic grid.

- Easy for CNNs but memory intensive (resolution grows cubically).

Implicit Representations

Represent 3D shapes as continuous functions f(x,y,z) → value (e.g., density or signed distance).

- Examples: NeRF (Neural Radiance Fields).

- Compact and differentiable — great for generative AI.

Applications of AI in 3D

  • - Reconstruction (from images or scans)
  • - Generation (new 3D assets from text or 2D input)
  • - Editing and style transfer
  • - Simulation and robotics perception

Image-to-3D Generation

Goal: infer a full 3D model from one or more 2D images.

Challenge: 3D structure is not directly visible — need prior knowledge and multi-view reasoning.

Common Techniques in Image-to-3D

  • - Neural Radiance Fields (NeRF) and variants.
  • 3D Gaussian Splatting for real-time rendering
  • Diffusion models trained on 2D–3D paired data
  • Multi-view supervision using differentiable rendering loss

Example: NeRF (2020)

Neural Radiance Field = MLP mapping (x,y,z,view_dir) → color + density.

- Optimized to reproduce images from multiple camera views.

- Revolutionized view synthesis and 3D reconstruction.

- NeRF Studio: a simple API that allows for a simplified end-to-end process of creating, training, and testing NeRFs.

Example: Gaussian Splatting

(a gentle introduction here and here)

A modern 3D representation using 3D Gaussian primitives instead of voxels or meshes.

  • Each Gaussian stores position, color, opacity, and scale (like a soft 3D blob).
  • Scenes are represented by millions of tiny overlapping Gaussians.
  • Rendering = projecting and blending these Gaussians from a camera view.

Advantages: Real-time rendering (60+ FPS), continuous surfaces, photorealistic results.

Used in: 3D reconstruction (NeRF→Gaussian), image-to-3D diffusion models (LGM, GaussianDreamer).

Image-to-3D SOTA Examples (2023–2025)

  • Zero123++ / Zero123++ – diffusion model generating novel views from one image
  • Wonder3D – multi-view diffusion with depth conditioning
  • LGM (Large Gaussian Model) – Gaussian-based 3D representation for fast generation

Text-to-3D Generation

Goal: create a 3D object directly from a text prompt like “a red chair with golden legs”.

- Combines text understanding (via CLIP or language models) and 3D synthesis (via NeRF or gaussian splatting or diffusion).

Challenges of text-to-3D

  • Training data scarcity for 3D
  • High computation and memory cost
  • Ambiguity of text (multiple valid 3D outputs given the same prompt)

Techniques Behind Text-to-3D

  • CLIP or LLM for semantic understanding
  • Score Distillation Sampling (SDS) from 2D diffusion models
  • 3D Gaussian Splatting for differentiable scene representation
  • Latent NeRF or mesh optimization guided by text-image loss

Early Text-to-3D models

  • Dream Fields (2021): optimize NeRF guided by CLIP text-image similarity.

Recent approach: Diffusion-Based Text-to-3D Models

Recent models use 2D diffusion models as priors to guide 3D generation.

  • Score distillation sampling (SDS)
  • Latent diffusion (as in Stable Diffusion)
  • Gaussian splatting for fast, consistent geometry

Text-to-3D (2024–2025)

  • DreamFusion: text-to-image diffusion + NeRF
  • Magic3D (NVIDIA): two-stage coarse-to-fine optimization
  • Fantasia3D: explicit geometry and texture optimization
  • GaussianDreamer Pro real-time diffusion-based text-to-3D, also for animation

State-of-the-Art Commercial AI for 3D modelling (2026)

  • Tripo P1.0: Breakthrough native 3D diffusion; generates complete low-poly assets in ~2 seconds.
  • Meshy 7: Full AI pipeline handling generation, auto-retopology, and auto-rigging.
  • Seed3D 2.0: Currently leading in blind human-preference tests for structural and texture accuracy.
  • Rodin Gen-2.5: Film-grade generation outputting ultra-high-density meshes (10M+ polygons).

Hunyuan3D 3.1 (Tencent, 2026)

The latest evolution of Tencent's text-to-3D & image-to-3D pipeline, shifting from multi-view distillation to native 3D diffusion.

Models and demos available on GitHub and Hugging Face for Hunyuan3D series.

Hunyuan3D 3.1 (Tencent, 2026)

  • - Native 3D Diffusion: Bypasses 2D multi-view limits to generate true 3D structure directly.
  • - Extreme Resolution: Supports massive 1536³ geometry resolution for highly detailed mesh extraction.
  • - Production-Ready Outputs: Generates complete PBR (Physically Based Rendering) materials (base color, roughness, metallic).
  • - Speed & Fidelity: Produces high-quality, game-engine-ready assets with optimized topology in seconds.

Emerging Trends

  • 3D diffusion models trained natively on 3D datasets
  • Multi-modal foundation models combining text, image, video, and 3D
  • Integration with generative design and digital twins
  • World Models: AI that learns internal representations of the physical world to simulate and predict interactive environments.

World Models?!

World models learn the underlying physics, geometry, and dynamics of reality to predict what happens next, moving beyond simple frame-by-frame visual generation.

  • They could enable AI to "imagine" outcomes before acting.
  • Crucial for robotics, autonomous driving, and real-time interactive simulations.
  • Allow for the creation of explorable, complete 3D worlds from a single image or text prompt.
  • A quick example here

Recommended watching: Yann LeCun: World Models: Enabling the next AI revolution

State-of-the-Art World Models (2025–2026)

  • HunyuanWorld-1.0 (Tencent): Open-source model generating fully explorable 3D environments from a single prompt.
  • Atlas (World Labs): Multimodal model generating 3D worlds from single images with pixel-perfect camera control.
  • Genie 4 (Google DeepMind): Real-time interactive simulation model with native audio and physics.
  • Cosmos 3 (NVIDIA): Unified open-weights architecture designed for generating physics-accurate synthetic data for physical AI.
  • LTX-2.5: Open-weights model tailored for real-time interactive systems and robotic adaptation.
