What is a Foundation LLM Model? 🧱
🧠 Technical explanation:
- A massive AI model trained on a vast quantity of unlabelled data at scale.
- Mostly based on the Transformer architecture (characterised with attention mechanisms).
- Trained with unlabelled data using "self-supervised learning" (e.g., guessing the next word in a sentence).
- "Foundation" means it serves as a base: it can be adapted (e.g., fine-tuned) to a wide range of downstream tasks, rather than being trained for just one specific task.
- We also have foundation models for image or audio, in these few weeks we focus on the LLMs - foundation models for language.
🏢 Commercial Foundation Models (Closed-Source)
Models whose weights and architectures are kept private by the companies that made them. You access them via APIs or web interfaces.
- OpenAI: GPT-4o, GPT-5 (You probably have used these via ChatGPT)
- Anthropic: Claude 3.5 Sonnet, Claude 3 Opus, Claude Fable 5, Mythos 5
- Google: Gemini 1.5 Pro, Gemini 1.5 Flash, Gemini 4 Argon
🔓 Open Source Foundation Models
Models where the neural network weights (the learned parameters) are made publicly available for anyone to download, run locally, and modify.
🤔 Why are they made open source?
- Democratisation: Allowing researchers, hobbyists, and startups to build AI without paying massive API fees.
- Transparency & Safety: The community can audit the models for biases and vulnerabilities.
- Business Strategy: Big tech companies (like Meta) release them to commoditize some part of it, for example, the model layer, encouraging a global ecosystem of tools built around their architecture rather than competitors'.
Summary of Top Open Source LLMs (2024-2025 specs)
- Llama 3.1 (Meta): Comes in 8B, 70B, and 405B parameters. 128k context window. Highly capable, industry standard for open weights.
- Mistral / Mixtral (Mistral AI): E.g., Mistral NeMo (12B). Known for high efficiency and punching above their weight class.
- Gemma 2 (Google): 2B, 9B, 27B parameters. Built from the same research as Gemini. Great for running on local laptops.
- Qwen 2.5 (Alibaba): Strong multilingual and coding performance across multiple sizes (from 0.5B to 72B).
What can we do with these Foundation Models? 🛠️
The AI Development Pipeline:
- Simple Inference: Asking the model a question and getting an answer. (Today)
- Prompt Engineering: Crafting the optimal text input to guide the model's behavior. (Today)
- Fine-Tuning: Training the model further on your own custom dataset. (Next weeks)
- RAG (Retrieval-Augmented Generation): Connecting the model to external databases/documents. (Next weeks)
- Agents: Giving the model tools to act autonomously (browse web, run code). (Next weeks)

Let's dive into Prompt Engineering 💬
What is Prompt Engineering?
It is the practice of designing, structuring, and optimizing the input text (prompts) to get the most accurate, relevant, or creative output from a Large Language Model.
"Programming in natural language."
📝 Prompt Engineering Techniques:

1. Zero-shot vs. Few-shot prompting
- Zero-shot: Asking the model to do something without giving examples. (e.g., "Translate this to French: Hello")
- Few-shot: Providing a few examples in the prompt to show the model the exact format/logic you want before asking the final question.
📝 Prompt Engineering Techniques:

2. Role-Playing / System Prompts
- Assigning a persona to the AI.
- E.g., "You are an expert art historian specializing in the Renaissance. Explain..."
- This drastically shifts the vocabulary, tone, and depth of the model's response. [EXPERIMENT IT within some domain/topic that you like]
📝 Prompt Engineering Techniques:

3. Chain-of-Thought (CoT) Prompting
- Encouraging the model to think out loud.
- Adding phrases like "Let's think step by step" forces the model to break down complex problems into logical parts, significantly reducing hallucinations and math errors.
📝 Prompt Engineering Techniques:

4. Output Constraints and Formatting
- Telling the model exactly how to present the data.
- E.g., "Output the response as a JSON array," "Use a bulleted list," "Keep the response under 50 words," or "Do not use the word 'delve'."
